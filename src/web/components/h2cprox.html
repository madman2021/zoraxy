H2C Proxy

Forward an entire subdomain to a cleartext HTTP/2 backend, such as a gRPC service.

Uses Zoraxy's public listening port and certificate store. For native gRPC clients, enable TLS and HTTP/2 in General Settings and install a certificate for the domain. The connection from Zoraxy to the backend is unencrypted HTTP/2.

Each configured domain belongs to H2C Proxy and takes precedence over matching HTTP Proxy rules, including wildcards. HTTP Proxy authentication, virtual directories, plugins and header rewrites do not apply. Select an access rule here and configure authentication in your backend. WebSocket upgrades and CONNECT tunnels are unsupported.

H2C Services

Stopped services return HTTP 503 and retain their domains. Stopping, editing or deleting a service disconnects its active streams.
